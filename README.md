# 💻 Run Locally

> **You only need to set up the frontend!**  
> It automatically connects to our live backend and database. No backend setup needed.

### Prerequisites
- [Node.js](https://nodejs.org) (v18 or above)
- npm
- Git

### Steps

**1. Clone the repository**
```bash
git clone https://github.com/hrutujagite/CareCrew.git
cd CareCrew
```

**2. Go to the frontend folder**
```bash
cd carecrew-frontend
```

**3. Install dependencies**
```bash
npm install
```

**4. Start the app**
```bash
npm start
# or
npm run dev
```

**5. Open in browser**
```
http://localhost:3000
```

That's it! Use the demo credentials on the login page to explore. ✅

> ⚠️ If the app takes ~30 seconds to load on first visit, the backend is waking up (free Render tier) — just wait and refresh.
